# DecodeLabs-Data-Analytics-Project-4 – Data Visualization

## Project Overview

This project focuses on Data Visualization using Microsoft Excel to transform raw data into clear and meaningful visual insights.

## Objectives

- Create meaningful data visualizations
- Identify trends and patterns
- Present data in an easy-to-understand format
- Summarize key insights from the dataset

## Tools Used

- Microsoft Excel
- Google Sheets

## Dataset

The project uses the provided Data Analytics dataset for creating visualizations and analyzing business-related patterns.

## Project Outcome

The completed visualizations provide a clear representation of the dataset and help communicate important insights effectively.
